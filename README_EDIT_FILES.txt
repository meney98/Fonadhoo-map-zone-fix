EDIT THESE FOUR FILES ON GITHUB:

1) house_names_edit.json
   Change house names shown/searchable on the map.

2) house_information_edit.json
   Change house number, Area/SS, feeder, distribution box, breaker and meter.

3) block_names_edit.json
   Change the name assigned to each BLOCK-xxxx.

4) block_information_edit.json
   Change block house number, Area/SS, feeder, distribution box, breaker and meter.

index.html is already connected to these four files.
After editing a JSON file on GitHub, commit the change and refresh the GitHub Pages map.
