ONLY EDIT THESE FOUR FILES

HOUSE:
1. house_names_edit.json
2. house_information_edit.json

When you rename a house in house_names_edit.json, use that NEW name as the key
in house_information_edit.json. The map will then show the new name and its information.

BLOCK:
3. block_names_edit.json
4. block_information_edit.json

When you rename a block in block_names_edit.json, use that NEW name as the key
in block_information_edit.json. Keep "blockId" inside the information record.

houses.json and blocks.json are NOT used and are NOT included.
